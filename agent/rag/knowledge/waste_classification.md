# 建筑垃圾分类与再生材料标准

## 建筑垃圾主要类别
- 混凝土块：可破碎为再生粗骨料 / 细骨料，替代天然骨料用于非结构或低强度结构用途。
- 砖瓦渣：破碎后可用于路基垫层、砌块生产，优质老砖（如石库门青砖）可整料保留用于装饰再利用。
- 砂浆、抹灰层：分选后可制备再生砂浆，或作为填料。
- 钢筋 / 金属：分选后进入金属回收产业链，不进入骨料产线。
- 木材、包装物：作为可燃/可回收物单独分流，不与无机固废混料。

## 资源化利用一般流程
1. 现场分拣：按材质初步分离，避免有害/不可回收物混入。
2. 破碎筛分：多级破碎，按粒径分级（通常分粗骨料 >5mm、细骨料 <5mm）。
3. 除杂：磁选去除金属，风选/水洗去除轻质杂质。
4. 检测：级配、压碎值、含泥量等指标需满足 GB/T 25177《混凝土用再生粗骨料》
   与 GB/T 25176《混凝土和砂浆用再生细骨料》的相关要求。
5. 产线加工：合格骨料进入再生砖、再生混凝土制品或透水材料产线。

## 常见资源化利用方案与转化比例（经验区间，用于演示，非精确核算值）
- 混凝土块 → 再生粗骨料：转化率约 60%-75%
- 混凝土块 → 再生混凝土制品（如再生砖）：约 1.3-1.6 吨废料可产出 1 吨再生制品
- 砖瓦渣 → 路基垫层材料：转化率约 70%-85%
- 老青砖 → 整料再利用（装饰/摆件）：视完好率而定，通常 20%-40% 可整料利用，其余进入破碎流程
